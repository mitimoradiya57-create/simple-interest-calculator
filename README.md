# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based application that calculates simple interest based on user-provided inputs.

## Features
- Accepts principal amount from the user.
- Accepts rate of interest.
- Accepts time period.
- Calculates simple interest.
- Displays the calculated simple interest and total amount.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used
- Bash Scripting
- Git
- GitHub
